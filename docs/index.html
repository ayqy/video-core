材料与版本

用自己的课程与素材组织内容，保留来源和许可。修改形成版本，历史工程与原素材继续可取回。

声音与成片

编排分镜、声音和字幕，生成实际预览。成片需要由你完整看听，核对事实、价格、术语与使用权利。

按需协作

可选择把指定版本送到私有 iCloud 审稿，也可跳过云端服务，在设备上整理、制作和备份。

先从一份离线练习开始

在应用“设置 → 首启自检与发行说明”中，选择“准备可重开的离线练习”。练习使用明确标注的合成资料，不需要模型账户、购买或高级模块，也不代表真实商品或经营结果。

真实工程的人工编辑器、游戏和卡通渲染分别核验对应权益。具体商品、价格及是否可购买，以实际商店返回的内容为准。软件权益不包含无限模型额度、素材授权、代做视频或代运营服务。

资料留在你选择的位置

工程、版本、素材和经营记录默认保存在本机。只有你配置外部账户、核对范围并发起操作时，应用才提交相应生成请求或创建指定版本的私有云审稿。备份和导出由你选择保存及分享位置。
