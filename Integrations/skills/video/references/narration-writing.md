# 5 类语言缺陷：识别方法 + 代表性样本




## 终极检验标准




**"在中国，没有人会这么说话"** —— 触发此感觉必须改。




辅助自检：把这个词/句代入"朋友发微信给你"的场景，发出去觉得怪就换掉。




---




## A 类：翻译腔




### 识别方法




1. 读一句话，问："这是中文母语者的自然表达吗？"

2. 检测特征：

   - 长复合修饰（定语超过 10 字还没到主语）

   - 英文短语直译（"做了一个判断" = made a judgment）

   - "的"连用超过 2 个

   - 名词化动词（"进行了优化" → "优化了"）




### 修复原则

拆长为短。问自己"用中文聊天怎么说这件事"，然后写下来。




### Few-shots

| 原文 | 修复 |

|------|------|

| 走下来教训不少 | 这半年踩的坑不少 |

| 做了一个判断 | 想明白一件事 |

| 三个更深的层次 | 更靠后的三件事 |




---




## B 类：网络梗黑话




### 识别方法




1. 这个词是否只在特定网络社区流行？

2. 三年后读者还能看懂吗？

3. 放在正式技术分享里是否违和？




### 修复原则

换平实表达。但技术圈已通用的（"卷""打醒""打脸"）可保留。




### Few-shots

| 原文 | 修复 |

|------|------|

| 某个夜跑 case 多炸 | 极端 case 说明不了什么 |

| 拉满 | 做到极致 / 直接删掉 |




---




## C 类：硬汉腔凹姿态




### 识别方法




1. 是否在用暴力/军事隐喻制造冲击感？

2. 是否在凹"技术老炮"人设？

3. 删掉这个词换成平实说法，信息量有损失吗？如果没有，就是凹姿态。




### 修复原则

直说事实。隐喻还原为具体描述。




### Few-shots

| 原文 | 修复 |

|------|------|

| 教训很硬 | 教训很直接 |

| 边界条件再砍一刀 | 边界条件进一步收紧 |

| 数据上化妆 | 好看的数字放大，差的藏起来 |




---




## D 类：生造词




### 识别方法




1. 百度/Google 这个词，能找到广泛使用吗？

2. 读者是否需要停下来猜含义？

3. 是否是英文术语硬翻成中文后不通？




### 修复原则

换通用术语，或拆成短语解释。




### Few-shots

| 原文 | 修复 |

|------|------|

| 隐线 | 容易被忽略的一层 |

| 反馈环 | 闭环 / 反过来改前一环节 |

| 量化锚点 | 可量化的硬指标 |




---




## E 类：词义错配（最隐蔽）




### 识别方法




**核心问题："中国人在什么场景下用这个词？"**




如果答案与当前语境不匹配，就是词义错配。这类错误语法对、语感也不算差，但用错了。




补充检测：

- 这个词通常出现在什么类型的文本里？（新闻/文学/日常/法律）

- 这个词有没有强烈的领域关联？（如"花边"关联娱乐八卦）




### 修复原则

查实词义再用。不确定时换一个确定没问题的词。




### Few-shots

| 原文 | 词的实际语境 | 修复 |

|------|-------------|------|

| 花边新闻 | 娱乐八卦/明星绯闻 | 删除，直接说事实 |

| 判官 | 阴司鬼差/阎王下属 | 裁判 |

| 长成 | 生物生长（孩子长成大人） | 演变成 |

使用前必须确认语义与当前语境匹配：

## 机械表达模式（全文出现≥3 次必须打散）




| 模式 | 替代方案 |

|------|----------|

| 不是X，是Y | 直说Y / "本质就是Y" / "关键在于Y" |

| 更值得讲的是 | 直接讲 |

| 最XX的是 | 换具体描述 |

| 真正的XX在于 | 直说 |




---




## 过渡句陷阱




以下句式一律删除或改写（删掉后如果逻辑不断裂，就不该存在）：




- "但这还不是最……的部分"

- "更值得注意的是，"

- "让我们来看看……"

- "接下来要说的，才是重点"

- "有意思的地方在这里"




中文好的过渡，是读者感觉不到过渡的存在。




---




## 书面距离感（高危词替换表）




| 高危词 | 替换方向 |

|--------|----------|

| 荒诞 | 离谱 / 说不通 |

| 讽刺 | 有点意思 / 偏偏 |

| 令人…… | 拆开重写——"令人深思" → "你会忍不住想" |

| 残酷 | 没办法 / 难受 |

| 深刻 | 直接删掉，说具体的 |

| 震撼 | 没想到 / 真的没想到 |

| 难为情 | 不好意思（人际）/ 不光彩（数字） |

## 故事与镜头

知识解说候选要把知识讲成有前因后果的短故事：先交代人物眼前想完成的事，让选择带来可见后果，再由条件变化或反事实形成转折，最后让观众从经历理解知识结论。各次比较固定其余条件，人物、时序、资源数量和动作保持一致；悬念来自尚未解决的问题，不堆无意义的过渡句或只罗列定义和数字。人物和场景需要什么，先从内容推导。
以儿童绘本故事为内容标杆：每一页都承担必要讲述，画面故事感强、情节连贯，每页文字很少，用与文字匹配的精彩画面展示关键行动和后果。逐镜说明本镜推进了什么，删除能无损移除的重复说明；绘本标杆不把受众限定为儿童。
故事、讲解台词和上述自然汉语规则跨各种视频形式生效，包括图形动画、彩铅、游戏化讲解、卡通及混合形式，不能只应用于某一种视觉风格。
原材料没有真实人物事件时，只能明确写成作者假设或示意故事，不能冒充真实经历、实测结果或现实规律；已给定事实、数字、单位和适用边界不能为戏剧效果改掉。
用户明确只需事实说明、操作步骤、技术短片或其他非故事用途时，按该用途组织，不强加人物或故事。这些指导只约束本次知识解说候选，不改变普通剪辑、已有原稿或素材操作。
完成候选后，按上述完整规则逐句检查自然汉语、词义和重复表达。关键词提示不能代完整审稿，不自动改写作者原稿，也不构成事实、权利、字幕或声音审核；候选仍须作者逐句核对。
