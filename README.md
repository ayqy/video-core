- CLI 宿主为 macOS 14 及以上，构建需对应 Xcode / Swift 工具链；共享库仍保留历史 iOS 17 兼容声明，不代表发行手机 App。
- CLI：构建后先查询 `video schema`、`video capabilities`；原生 CLI 不是无认证远程服务。
- 更新器：`video-install --help`说明固定发行者签名目录包和程序/数据成对回滚；不提供私钥、许可证或未签名安装开关。
- Skill：参阅 `Integrations/README.md`；安装器只向用户选择的项目目录安装，不更改模型账户或读取密钥。
- 免费包不含高级模块，模拟或卡通高级绘制请求会明确报告缺少能力；已有工程、素材和历史导出仍可读取。
- DinoBuiltinAssets、VoicePromptBuiltinAssets、BubbleKnowledgeBuiltinAssets与MotaBuiltinAssets是固定被动素材包的导入器源码；完整Mac内置图片、原音包和依赖这些资源的集成测试不在本包。导入器核对原字节及来源，不能把导入成功当用途授权或声音听审。普通入门配方仅另附三件固定CC0原Ogg及原作者许可，不要求安装Mac素材包。
- 规则测试与源文件摘要见 `SOURCE-MANIFEST.md`。此分包检查不等于编译、设备验收或公开发行已经通过。

## 独立制作入门

`Integrations/examples/README.md`提供可直接运行的普通免费制作配方：固定公开原件与许可、脚本和剪辑、真实英文提示录音、成片四件、质量交接及含源恢复。提示录音不冒中文知识旁白，人工声音/字幕/整片审核保持待审。

`ThirdParty/GameAssets/voiceover/`仅包含该配方已核的Ready、Go、You win三件英文原Ogg及原作者CC0许可。配方先核本地原件或既有缓存的精确SHA，再补缺；坏缓存保留并拒绝覆盖，缺少整组本地原件时才走既有固定原作者包。原件不适用本项目源码的Apache许可，具体来源与SHA见配方说明。

中文讲解配音见 `Integrations/expressive_tts.md`：用户自行准备固定的本地CosyVoice-300M-SFT模型和独立环境，再用预设音色离线生成完整语句，默认中文男；缓存按实际模型、引擎、环境、音色、原文和种子身份复用。兼容文件名不表示已提供情绪控制，非空`instruction`会明确拒绝；声音效果与整片审核仍须完整试听。本包只分发工具、规则测试、指南和环境锁，不附带模型权重、第三方运行时或生成音频。

游戏补充素材见`Integrations/README.md`中的`game_asset_production.py`：先冻结内容需要，再按明确的游戏风格参考解析素材，缺项交给真实图像工具，登记原始PNG、实际提示和具体来源后，通过正常CLI导入、来源核对及一次版本编辑绑定角色。它不附带游戏图片或高级绘制模块，不生成实体、改变知识规则或自动确认人审。

`Integrations/causal_story.py`保留道路示例；`knowledge_story.py`把完整分层计划和明确的v3来源通过正常Core录制、比较、dry-run及一次CAS接到已有场景动作。金额、归属、前置关系及实际事件须分别核验，不能用请求动作代替执行。`storyCausality`是可选的Host内容合同；原场景没有此字段仍可读取，模型、原始轨迹和讲稿不进入插件视觉白名单。显式计划v2另支持单一现有行动成本的反事实，原v1编码与恢复保持；成本只能改一个cost，必须有实际行为差异。当前通用入口不附素材或高级绘制，不支持旧知识模型v1/v2转换、任意规则正文反事实或交货付款，不把规则测试当作完整成片审核。

显式`CartoonRig.version=2`可容纳最多八个独立角色，必须使用卡通schema6；旧rig1仍最多四人，旧cartoon5不能承接rig2。模块的free/closed来源、权限及policy9保持原范围，高级人物绘制实现和素材仍不在公开源码包中。

`Integrations/story_planning.py`按人物动机、剧情框架、细节动作和镜头四层生成内容，先检查父层及来源，再提出素材需求；`story_evaluation.py`按相同理解与表现目的比较修改前后，保各项观察和失败原因。这些工具不读取素材库存、不选择默认模型、不发网络请求，也不自动批准作品。可选`CartoonPresenter`合同支持引用实际图片图集与表情/口型序列，明确要求相容的cartoon schema7；旧nil、rig1/rig2入口保原条件。原始剧情与知识轨迹留在Host，角色绘制实现、生成图片、原音和本地项目仍不在公开包中。

普通图片图层可用`sourceRect`精确选择原图区域，或用`imageSequence`按源帧连续切换同一真实图集的不同姿态；两者互斥。静止裁区不冒充动画。序列裁切、拆分、变速和停顿保留明确源窗口，仍受32层与实际图片来源校验。它们属于普通免费图层，不要求高级人物模块；公开包不附带业务角色、图集或原音。

公共仓库的`free-production`工作流重新编译最新公开CLI，完整执行VisualCacheResume分段缓存媒体规则，再通过实际CLI验证导入、正常编辑、拆分、零元普通制作、全帧解码及含源恢复。每项核对真实方法身份，不允许跳过。其余未修改载荷逐件固定到已通过的32ba347基准，沿用证据仅适用于原输入与调用条件；不重复运行旧21项图层、旧62项解说员规则或未变Python模块，也不据此推断闭源人物画师或业务成片质量。工作流不安装Mac App、付费插件或激活材料，不读取服务凭据或上传私人工程；公开源码、合成测试像素和最小链通过不代表真实作品的声音、素材权利或整片人工审核通过。
