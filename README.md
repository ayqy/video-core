中文讲解配音见 `Integrations/expressive_tts.md`：用户自行准备固定的本地CosyVoice-300M-SFT模型和独立环境，再用预设音色离线生成完整语句，默认中文男；缓存按实际模型、引擎、环境、音色、原文和种子身份复用。兼容文件名不表示已提供情绪控制，非空`instruction`会明确拒绝；声音效果与整片审核仍须完整试听。本包只分发工具、规则测试、指南和环境锁，不附带模型权重、第三方运行时或生成音频。

游戏补充素材见`Integrations/README.md`中的`game_asset_production.py`：先冻结内容需要，再按明确的游戏风格参考解析素材，缺项交给真实图像工具，登记原始PNG、实际提示和具体来源后，通过正常CLI导入、来源核对及一次版本编辑绑定角色。它不附带游戏图片或高级绘制模块，不生成实体、改变知识规则或自动确认人审。

`Integrations/causal_story.py`保留道路示例；`knowledge_story.py`把完整分层计划和明确的v3来源通过正常Core录制、比较、dry-run及一次CAS接到已有场景动作。金额、归属、前置关系及实际事件须分别核验，不能用请求动作代替执行。`storyCausality`是可选的Host内容合同；原场景没有此字段仍可读取，模型、原始轨迹和讲稿不进入插件视觉白名单。显式计划v2另支持单一现有行动成本的反事实，原v1编码与恢复保持；成本只能改一个cost，必须有实际行为差异。`examples/knowledge_delivery.py`另示先交货后付款：一件自有货物先完成真实交付，较晚事件才给同一卖家实际货款；不交货分支不收款，金额取Core结算。两种付款名称共用转账去重，剧情与动作均校验实际买卖双方和前置。当前通用入口不附素材或高级绘制，不支持旧知识模型v1/v2转换、任意规则正文反事实或商品估值，不把规则测试当作完整成片审核。

显式`CartoonRig.version=2`可容纳最多八个独立角色，必须使用卡通schema6；旧rig1仍最多四人，旧cartoon5不能承接rig2。模块的free/closed来源、权限及policy9保持原范围，高级人物绘制实现和素材仍不在公开源码包中。

`Integrations/story_planning.py`按人物动机、剧情框架、细节动作和镜头四层生成内容，先检查父层及来源，再提出素材需求；`story_evaluation.py`按相同理解与表现目的比较修改前后，保各项观察和失败原因。这些工具不读取素材库存、不选择默认模型、不发网络请求，也不自动批准作品。可选`CartoonPresenter`合同支持引用实际图片图集与表情/口型序列，明确要求相容的cartoon schema7；旧nil、rig1/rig2入口保原条件。原始剧情与知识轨迹留在Host，角色绘制实现、生成图片、原音和本地项目仍不在公开包中。

普通图片图层可用`sourceRect`精确选择原图区域，或用`imageSequence`按源帧连续切换同一真实图集的不同姿态；两者互斥。可选`imageFlipHorizontal`只改变Host绘制的普通图片左右朝向；旧图层省略该字段时保持原编码和画面。该字段不进入插件快照、既有RPC schema或其摘要，RPC输入明确拒绝注入该Host专用字段。静止裁区不冒充动画。序列裁切、拆分、变速和停顿保留明确源窗口，仍受32层与实际图片来源校验。它们属于普通免费图层，不要求高级人物模块；公开包不附带业务角色、图集或原音。`actor_motion.py`依据调用者明确给出的裁区、脚点、手部锚点和有限路径生成可编辑姿态与接触坐标；元数据不是图像识别、真实画面接触验收或业务因果来源。

真实图片或录屏镜头可显式设置`mediaPresentation: {"version":1,"layout":"fullFrame","backgroundColor":"FFFFFF"}`，使用普通媒体纯画面模式。Host不再叠加通用VIDEO标签、重复标题或页码时间，保留电影字幕与明确作者图层；原件先按显式`mediaFraming`取景，默认居中等比容纳于稳定内容窗，不拉伸或额外裁源。作者显式设置`x/y/scale`时仍按原变换绘制，并裁在固定内容窗内，不能进入字幕区域。背景为六位RGB，默认白色。实际源资产、源窗口、速度、停顿及声音映射沿原规则校验；模式增删或背景色变化使声音、字幕及完整预览需要重新复核。旧镜头省略该字段时保留原编码与画面；该Host普通媒体字段不扩展高级RPC或模块权限。

三维资源SDK提供`ModelPackageMedia.importPackage`与`load`。跨组原PNG可用`textureBindings: [String: ModelTextureBinding]`显式指定：键必须是DAE声明的规范相对别名，值为所选来源目录内实际PNG的URL及预定SHA256；指定原件缺失或不符时拒绝，不猜同名文件或回退。原DAE、PNG字节与引用关系保持入库，返回资产仍须正常事务保存并独立记录来源。加载只使用当前工作区已核原件；材质纹理由原sampler、surface、image与UV绑定链确定，直接解码为图像，保留常量和原光照模型。仅缺少材质显示名时，临时原生加载数据补`name=id`；该运行时投影不写回原件。当前适配支持明确的COMMON材质及FCOLLADA法线，歧义、稀疏UV或未支持采样扩展明确拒绝。`verifiedByteClosure`沿同工作区、来源权利和安全CAS读取校验冻结完整原件；`loadByteClosure`对已经冻结的字节重新核对SHA、真实DAE元数据与PNG后技术解码，不创建数据库或来源证明，不授媒体审核。

通用模型银行协议仅用于明确的game schema9：同一次完整调用按`begin/append/commit`上传原DAE及PNG，后续帧只携带绑定清单摘要和调用摘要的引用；每帧输入及输出指纹覆盖全部实际资源。银行最多两份、合计64MiB、每份最多512件，每块最多512KiB；单图24M像素和合计48M像素沿既有预算，超限明确拒绝。`release`、截止与关闭清理服务持有字节，正在运行的任务保留自己的不可变快照。原schema8图片预算、八种RPC方法和旧编码保持；旧模块不能接收三维输入或悄悄回到二维。Host在报价、任务、缓存和绘制前要求受信schema9及完整Scoped调用，`RenderResources`的只读模型银行和本进程取消门禁不提供文件或网络权限。公开包不包含高级三维绘制实现、动森原件或任何合法高级包；模块仍须经原固定发行者、真实代码签名、策略与权益门禁安装。缺少相容模块时正常入口明确拒绝。

`Integrations/model_material_import.py`和`native/ImportModelMaterials.swift`用于显式指定的已有工作区、项目及当前版本。调用者提供原DAE和每个PNG的路径、SHA、大小与来源/许可声明；必须先真实编译Swift辅助入口，再由实际SDK解析、导入，经正常事务追加固定本地非商业素材和来源记录，保持原修订与其他数据。JSON声明不能替代真实inspection或主CLI模型入库结果，也不授商业、review或上传权限。Python只调用已编译且由调用者冻结的辅助程序；真实已有工程链另行验证。历史Mota导入工具仅保留作旧工程追溯。公开包不附业务模型、游戏原件或素材清单，通用SDK和相容Host不代表完整动森成片已达标。

`ModelInstance3D.materialInterpretation`是可选的显式呈现设置。省略时保留旧编码与原顶点色、RGB法线行为；作者可分别选择忽略顶点色、将法线解释为`redGreenPositiveZ`（RG映射XY，Z固定正向并由绘制端归一化）。`opaqueDiffuseMaterialIDs`仅为明确选中的原DAE材质ID忽略diffuse alpha，独立transparent、transparency等控制仍保留；未知或重复ID拒绝。设置进入工程摘要、正常编辑、锁定保护和含源备份；不改原模型或PNG，也不依据文件名和像素自动推断。SDK的`materialsBySourceID`映射来自原material/effect与实际原生名称的唯一对应，保留原名称。该设置不表示原游戏缺失的BFRES材质参数、透明度、混合贴图或完整着色器已还原；实际支持须由相容高级绘制端确认。

## 显式知识制作入口

`Integrations/produce_knowledge.py`通过共享`production_workflow.py`执行有限的`prepare`、`render`、`verify`三个阶段。调用方须先提供完整、逐层评估过的`StoryPlan`、明确的v3有限规则来源与呈现计划、真实原生场景、所需素材原件及来源/许可说明，以及完整原音、生成来源回执和同一请求实际SDK逐词边界。工具不自选故事模型、不从素材库存决定内容，不附默认业务故事、配音、游戏图片或闭源绘制实现；计划/规则格式检查不代替知识真实性与实际效果判断。

声明是版本1的二进制或XML plist，固定包含`name`、`voice_identifier`、`aspect`、`fps`、`viewport`、`presentation`、`scene`和`materials`。当前声明入口支持30fps的1280×720横屏或720×1280竖屏。`presentation.story`承接完整四层内容计划，`sources`遵守既有1至3个v3有限来源及明确干预合同；来源模型与实际结算继续由正常Core录制和核验，不执行用户脚本。`scene`须按完整原音的实际帧轴编排，不注入声音、已确认字幕或因果证明，旁白与计划全文一致。素材以稳定键声明路径、SHA-256、来源、所有者、用途说明和许可；场景用`{"$asset": "key"}`或`{"$source": "key"}`引用，实际导入后才绑定真实资产与证据身份。素材许可仍由调用方核对，不因本地导入取得商用或上传授权。

先运行`python3 -B Integrations/produce_knowledge.py --help`检查参数。每阶段均传同一组明确参数：`--document`、`--binary`、`--binary-sha256`、`--home`、`--output`、`--voice`与`--boundaries`，末尾依次使用`prepare`、`render`、`verify`；专用home保留冻结输入、原报价、原任务与阶段凭据，重试沿原身份恢复。验证实际四件字节、完整声画解码、首秒声音及原音首尾相关，并独立恢复完整备份；这些技术检查不等于逐段原音一致、声音完整听审、字幕确认或整片视觉批准。

原脚本含数字或术语读法时，可另传`--speech-plan`完整二进制plist。先通过正常CLI的`speech normalize`取得原文、规范稿、词典及UTF-16映射，明确选择`voiceIdentifier`并确认读法；完整原音回执与同次SDK词界必须覆盖该规范稿。生产入口再次核对正常Core规范化结果，冻结整个计划及原件；字幕保留原脚本，例如原文`3枚`、朗读`三枚`。仅在完整TN段端或未改写文字内确定镜头文本边界，再匹配SDK实测整词；改写段或SDK词内部切镜均拒绝，不推算原文字或音素时间。此选项仅适用于实际SDK词界路径，不与保留轴、作者估算轴混用；读法确认不会授予声音听审、字幕确认或整片审核。

声明可显式设置`caption_policy: {"version":1,"kind":"observed-natural-cues","max_chars":24}`，在真实同请求SDK整词及精确TN安全切点上按自然句段拆分字幕；保留完整原文和标点、原音、既定镜头及动作。`max_chars`是作者按实际画幅、字体和阅读时间选择的8至120整数预算，24仅为示例，不保证不同画幅或制作形态使用同一预算都合适；最终仍由原生字幕布局检查和实际成片确认。无法在安全自然切点满足预算时明确拒绝，不截字或推算词内时间。旧声明省略该字段仍保持一镜一条字幕；作者估算轴与`retained_speech`模式均拒绝此策略，必须提供实际SDK词界。分段成功不会自动确认字幕、声音或整片。

若原SDK逐词文件已不可得，可显式提供`retained_speech`历史见证并省略`--boundaries`。见证逐件提供既有`prepared`、`quote`、`produced`、`inputs`、`speech-axis`和`backup`的绝对路径及SHA-256，并明确选择原修订工程的`revision-inputs`或正常生产入口的`speech-provenance`身份凭据，核对同一原工程的完整原音、字幕、镜头轴、来源与任务身份；它只接受该已冻结轴，不重建丢失词界，也不把历史计数写成新SDK观察。此历史模式要求这些原始见证均实际存在，不承诺任意旧目录均可自动迁移。

可选`--executor`与`--catalog`必须成对指向已安装的正常Host和模块目录；所有签名、兼容、策略与独立权益仍由Host原门禁决定。此入口不附带高级模块，不绕过真实游戏素材SDK导入，也不声称本轮获得高级风格的新媒体验收。
